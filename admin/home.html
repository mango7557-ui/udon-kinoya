저장 · 사진 · 접근 보호 안내

저장하면 현재 접속한 사이트의 데이터 저장소에 반영됩니다. 프리뷰와 실제 운영 사이트의 데이터는 별개입니다. 공통 로고·전화·공유 정보는 다른 페이지와 같은 키를 사용합니다.

사진은 선택 후 600KB 이하로 자동 압축합니다. 비우기는 기본 사진 복원이 아니라 해당 사진을 숨깁니다. 영상은 업로드 서버 없이 MP4 직접 주소로 지정합니다. 미리보기는 정적 콘텐츠 확인용으로, 유튜브/협력사/FAQ/뉴스/자료실의 동적 데이터와 버튼·상담 폼 동작은 실제 사이트에서 확인하세요.

이 화면 자체에는 보안 로그인이 없습니다. 운영 관리자와 데이터 API의 접근 보호는 별도 플랫폼 접근 규칙 설정이 필요합니다.
