💾 전체 데이터 백업/복원 (JSON·엑셀)

홈페이지 텍스트/사진 설정, 상담신청 내역, 유튜브 영상/쇼츠, 협력사 로고, FAQ, 뉴스, 자료실 — 7개 데이터를 전체 페이지 조회 후 JSON으로 백업합니다. 긴 사진값이 있는 기존 데이터는 JSON을 사용하세요. 엑셀은 셀 길이 제한 초과 시 중단합니다. 복원은 파일 전체 사전검증과 변경 건수 확인·복원 전 백업 후 순차 실행합니다. 기존에만 있는 행은 삭제하지 않으며 부분 실패는 자동 롤백하지 않습니다. 첨부파일 원본과 개인정보 백업은 별도로 안전하게 보관하세요. 과거 Base64 본문은 새로 DB에 복원하지 않습니다.

🤝 협력사 로고 관리

홈페이지의 "매장증명" 섹션과 "피플" 섹션 사이에 협력사/파트너사 로고가 3줄로 자동 스크롤됩니다 (상단·하단은 왼쪽으로, 중간은 반대로 오른쪽으로 흐릅니다). 각 줄에 로고를 하나 이상 등록하면 해당 줄이 화면에 나타나고, 등록된 로고가 하나도 없으면 전체 섹션이 숨겨집니다. 로고 이미지는 선택 즉시 자동으로 PNG로 변환되고 용량이 줄어듭니다. 링크 URL은 선택 입력이며, 입력하면 로고 클릭 시 새 탭으로 이동합니다.
