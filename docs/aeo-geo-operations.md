# 우동키노야 AEO·GEO 운영 체크리스트

작성: 2026-11-04. 현재 작업은 정적 파일 및 프리뷰 검증이며 운영 배포·검색엔진 제출을 수행하지 않았다.

## 목적과 한계

검색엔진과 답변 서비스가 공개 정보를 읽고 출처로 연결하기 쉽게 만든다. 상위 노출, 크롤링, AI 인용 또는 매출을 보장하지 않는다. llms.txt는 보조 안내 파일이며 모든 서비스의 표준이나 필수 지원 기능이 아니다. FAQPage 마크업이 유효해도 Google FAQ 리치 결과는 주로 권위 있는 정부·보건 사이트에 제한되므로 음식점 사이트의 리치 결과 노출을 약속하지 않는다.

가이드/llms.txt는 CMS에서 자동 생성되지 않는다. 관리자 변경만으로 정적 HTML의 메타·JSON-LD·가이드가 자동 갱신되지 않으므로 위 목록을 함께 검토해야 한다. 현재 사용자 레코드·CMS 키·DB 스키마는 변경하지 않았다. 원본 간 값이 다르면 임의 평균이나 추정으로 합치지 말고 운영자 확인을 받는다.

## 정적 콘텐츠 원칙

- `/guide/`는 앱 스크립트 없이 본문·8개 질문답변·원문 링크·자료 정리일·정보 정정 경로를 제공한다.
- FAQ의 `Question.name`과 `Answer.text`는 대응하는 h2와 `.answer-text`에 실제 표시되는 내용과 동일하게 유지한다.
- 변경한 날짜에만 dateModified/자료 정리일/해당 URL lastmod를 수정한다. 전체 페이지 날짜를 일괄 오늘로 바꾸지 않는다.
- 가맹비 지원·등록 매장 수는 자료 시점과 조건을 명시한다. 지점 사례를 평균·수익 보장으로 표현하지 않는다.
- 리뷰·평점·인증·특허 등록·외부 권위에 관한 근거 없는 마크업을 추가하지 않는다.
- 과거 송도점 페이지는 기록을 보존하면서 noindex, follow 및 과거 안내를 적용했다. 사이트맵과 Restaurant 마크업에서 제외했다. 새 정보가 확인되면 먼저 운영자에게 상태를 확인한다.

## 로컬/프리뷰 검사

- `/tests/aeo-geo.html`: 사이트맵에 기재된 51개 페이지 응답, title/description, canonical, JSON-LD 구문, hreflang 상호 링크, 가이드 FAQ 일치, 최신 숫자, robots, 이전 매장 검색 제외를 검사한다. 2026-11-04에 19/19 통과.
- `/guide/`: PC/모바일에서 헤더·목차·긴 본문·연락처 카드를 확인한다. 저장된 스크린샷은 시각 검사 자료이며 Google Schema 검증 서비스의 결과가 아니다.
- 변경 후 기존 홈/메뉴/매장 회귀 검사를 재실행한다. 테스트 페이지는 robots 및 noindex로 검색에서 제외한다.
- robots.txt는 크롤링 요청일 뿐 비공개 경로의 인증·접근제어 수단이 아니다. 보안은 기존 플랫폼 정책을 사용한다.

## 승인된 운영 배포 후 소유자가 할 일

1. 사용자가 배포를 명시적으로 요청하고 플랫폼 승인이 완료된 뒤에만 반영 완료라고 보고한다. 프리뷰 데이터와 운영 D1은 별개이며 자동 동기화되지 않는다.
2. `https://www.udonkinoya.com/` 및 `/guide/`, `/robots.txt`, `/sitemap.xml`, `/llms.txt`가 익명 방문 시 로그인·봇 챌린지 없이 읽히는지 확인한다. 접근 정책 변경이 필요하면 별도 승인 범위에서 플랫폼 설정으로 처리한다.
3. HTTP/비-www 등 중복 도메인의 리디렉션과 HTTPS를 실제 운영 환경에서 확인한다. canonical은 `https://www.udonkinoya.com/`로 유지했다. DNS·리디렉션·HTTP 응답 헤더는 이번 정적 수정으로 설정한 것이 아니다.
4. Google Search Console, Bing Webmaster Tools, 네이버 서치어드바이저에서 실제 소유자가 사이트를 인증하고 sitemap.xml을 제출한다. 인증 토큰을 추측하거나 가짜 태그를 넣지 않는다.
5. Google URL 검사 및 Rich Results Test/Schema.org Validator에서 운영 페이지를 점검한다. JSON 구문 통과와 검색엔진 색인/리치 결과 적격성은 별개다.
6. 네이버·카카오·구글 지도에 등록된 실제 지점명·주소·전화번호를 해당 소유자 계정에서 대조한다. 이번 작업은 외부 지도 정보를 수정하지 않았다.
7. 카카오 공유 미리보기와 캐시는 배포 후 따로 확인한다. 사이트 robots 허용만으로 플랫폼 방화벽/조직 접근 제한이 해제되지 않는다.

## 월별 점검

- 검색 콘솔: 색인 상태, 브랜드·지역·창업 검색어별 노출/클릭, 대상 페이지를 기록한다.
- AI 답변 확인: ‘우동키노야는 어떤 브랜드인가요?’, ‘창업비용에 보증금이 포함되나요?’, ‘구리본점 문의번호는?’ 등을 같은 조건으로 조회하여 답변 날짜·수치·인용 URL을 기록한다. 답변은 서비스·사용자·시점별로 달라질 수 있다.
- 문의 경로: 상담/매장 문의가 올바른 번호와 페이지로 연결되는지 확인한다.
- 새로운 매장, 폐점, 가격, 지원 정책이 바뀌면 원문 → 가이드·JSON-LD·번역 → llms.txt → sitemap lastmod → 테스트 → 승인 배포 순으로 갱신한다.
